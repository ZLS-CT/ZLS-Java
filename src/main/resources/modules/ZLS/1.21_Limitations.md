
:# §61.21 Limitations:

§6World Scanning:
    * Items that are only valuable due to NBT tags can't be tracked.
      This is because Hypixel doesn't send the full NBT for items after version 1.12.
      §eBest to use 1.8.9 for island scanning.

      §b§l --> This only effects World Scanning on 1.21.x.
              §b§lAka only items on Armor Stands, Item Frames, etc.
              §b§lAPI/Lobby Scanning is unaffected.
      
      §aExamples of items that are still tracked:
        * Exotics
        * Crystal
        * Seymour
        * Unapplied Skins
        * Admin Items (Space Helmets / Ancient Elevators)
        * ...and everything else not said in the next section

      §cExamples of items that can't be tracked:
        * Applied Skins
        * OG Backpacks / Cake Bags
        * Admin Spawned Items
